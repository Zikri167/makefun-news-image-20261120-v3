# The World in One Day — 20 November 2026

Entry for [Sum up 20 November's world news in one image](https://make.fun/c/news-image-20261120) on make.fun.

A deep-navy world-atlas infographic: the continents drawn as a cyan dot grid, with numbered gold pins marking where each story happened — Shenzhen, The Hague, Odisha, Riyadh, Kyiv, and deep space. Below the map, six numbered stories sum up Friday 20 November 2026: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, the ICJ's 9–6 genocide ruling against Myanmar, Cyclone Akvan hitting Odisha, a Houthi missile striking Riyadh's tallest tower, Europe signalling talks with Russia as missiles hit Kyiv, and Voyager 1 reaching one light-day from Earth.

`main.py` (Python 3.13, standard library only) copies the bundled `entry.png` to the output directory.
